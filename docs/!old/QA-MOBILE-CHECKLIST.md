# Mobile QA Checklist

1. Open the editor on a phone, dismiss any welcome/info modal, and load a blank canvas; expected: the preview appears, the Editor tab enables, and the canvas is centered.
2. Open Add Layer and create a Glitter Fill layer; expected: the layer appears in the list, the glitter gallery stays available, and Color Fill settings are reachable.
3. Open Add Layer and create a Sticker layer; expected: the new sticker layer appears selected and the Design drawer can browse sticker sources.
4. Open Add Layer and create a Text layer; expected: a text layer appears selected and the Text Properties panel shows the text input and typography controls.
5. Open Add Layer and create a Shape layer; expected: a centered default shape appears and Shape Properties plus the glitter gallery are available.
6. Activate the Shape tool and tap once on the canvas; expected: one default-size shape is created at the tap point.
7. Activate the Shape tool and drag out a box; expected: the rubber-band preview follows your finger and the created shape matches the dragged bounds.
8. Activate the Shape tool and long-press without moving; expected: a default-size shape is still created at the press point.
9. While a shape drag is in progress, place a second finger and pinch; expected: shape creation cancels and the viewport zooms instead of leaving a stray shape.
10. Select a shape with a border and reopen it after deselecting; expected: the visible shape does not jump and the selection box still wraps the border correctly.
11. Switch a shape border to Dotted and change Dot Spacing; expected: the spacing control appears only in dotted mode and the preview updates without shifting the shape.
12. Enter Mask Brush mode on a non-glitter layer and begin painting; expected: a glitter layer auto-creates without forcing the Design drawer open away from Brush Settings.
13. In Brush Settings and Eraser Settings, use the copy action and then Clear Paint; expected: settings copy across tools and Clear Paint removes painted strokes after confirmation.
14. Create Box text, use Fit to Text, and double-tap the text on mobile; expected: Fit to Text works only in Box mode and double-tap opens mobile settings with the text input focused.
15. Export a composition with multiple animated layers and transparency on iOS Safari; expected: export completes, the preview animates, and Share/Save preserves the animation.
