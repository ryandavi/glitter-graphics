How to install these brushes for Adobe Photoshop:

(Photoshop 7.0 was used in this example, other versions of Photoshop may vary.)

1. Open up Adobe Photoshop.
2. Go to Window on the top menu bar. Scroll down and choose Brushes.
3. There is an arrow button in the upper right corner of the Brushes dialog box that should have opened in the last step. Click it, then scroll down to Load Brushes…
4. Navigate to where the brush files that you want to load are located. Once you have selected the brush file that you want to load, click the Load button.
5. Your brushes should be loaded. If you experience problems getting the brushes to load, it may be because the brushes were made for a more recent version of Photoshop. In this case, you cannot load those. If the site where you downloaded them offers brush image packs or stamps, you can define them yourself and use them.
