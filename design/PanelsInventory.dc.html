Every right-panel type in the app

From updateSidePanelUI(): one #designPanel swaps between these modes by data-panel-mode. Design them one at a time, then re-check earlier ones for consistency. Status reflects this canvas, not the codebase.

A. Layer property panels

Shown when a layer is selected. All share the row + module system.

Text Properties iteratingtextSettingsSection · mode: text

Content (Text, Font, Spacing, Alignment) · Appearance (Fill, Opacity) · Transform · Effects (Border, Shadow).

Sticker Properties draftedstickerSettingsSection · mode: sticker

Content module (Asset + Adjust color: hue / saturation / brightness) · Appearance (Opacity) · Transform · Effects (Shadow). Uses buildAssetInfo.

Shape Properties draftedshapeSettingsSection · mode: shape

Content (Asset + Radius) · Appearance (Fill, Opacity) · Transform · Effects (Border with Style / Dotted / Dot gap / Edges / Placement / Layering, Shadow). Radius is a net-new control.

Fill Properties draftedglitterSettingsSection · mode: glitter

One paint slot (glitter / solid, scale, opacity, Advanced: texture position + hue / sat / bright). No transform. Read-only Mask summary.

Canvas Properties draftedbaseLayerSettingsSection · mode: base-layer

Appearance (background: image / transparent / glitter / solid) · Size (Image Size vs Canvas Size, two-mode) · Effects (Pixelate + Palette with Posterize / Dither branch) · Actions (Auto Glitter). The densest panel.

B. Tool-setting panels

Shown while a settings tool is active (Photoshop options-bar model), independent of selection.

Mask Settings (Brush / Eraser) draftedbrushSettingsSection · schema: brush

Brush Tip (Asset) · Stroke (Dynamics: size, softness, flow, spacing, smoothing, pressure; Scatter & Jitter) · Actions (copy opposite, reset, clear strokes). Title carries a Brush / Eraser tag.

Color Fill Settings draftedlayerSettingsSection · auxiliary

Only with the Color Picker tool on a glitter fill. Options (contiguous, invert, multi-select toggles) · Color selections (chip list) · Refine (color tolerance, edge feather).

C. State panels

No selection / Canvas home draftednoLayerSettingsSection · mode: no-layer

A lead line · Quick add (layer-type tile grid) · Project (name field, Open / Save) · Size (Image Size / Canvas Size, re-authored from modal settings-row-* markup). Shown on load and when nothing is selected. Not an accordion, a flat block list.

Multi-selection draftedmultiLayerSelectionGroup

Appearance (shared Opacity, "Mixed" when they differ) · Align (Align-to scope dropdown, Horizontal / Vertical / Distribute) · Actions (Group, Duplicate, Merge down, Delete).

Welcome / no image draftedmode: welcome

One .property-empty component: icon tile, title, subtext, an Open image primary action + New blank canvas. The same component replaces the five inconsistent empty states (three SVG, three literal emoji).

Auto Glitter wizard not startedautoGlitterSettingsSection · mode: auto-glitter

The stress test. Preview · Palette (scroll) · Color Matches (scroll, dynamic results, live status host) · Advanced (scroll) · Finish (pinned Cancel / Create Layers). Needs .panel-scroll + a pinned .panel-footer.

D. Asset browser

Gallery + search + filters drafteddesignGallerySection

Contextual per asset type: glitter, stickers, shapes, brush tips. Header (Back + title + count), search row, armed picker strip, active-filter chips, then a category grid (2-up folders) or an asset grid (4-up). Filter drawer redesigned: .property-group-label + chip rows + hairline dividers (no cards, no fourth uppercase level, no nested 200px scroll).
