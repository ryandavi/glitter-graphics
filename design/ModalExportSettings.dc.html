Same shell, same body rules as Settings; fixed viewport-fraction height with the body as the one scroll region. Format is a .segmented (GIF / MP4 / PNG); the groups below react to it (when: — MP4 shows Playback + MP4 Quality, GIF shows GIF Look / Colors / Dithering). Every control — the Format segmented, dropdowns, sliders+value, colorfield, number, switch — sits in the same 188px right-aligned band as Settings, so nothing (not even Format) stretches modal-wide; the colour field hugs its content. Reset is identical to Settings (rule D): per-row undo icon (hidden / hover / solid-when-changed — GIF colors shown edited), per-section icon on the .glabel shown only when that section has an edit (Quality yes, Output no), and the footer Reset all (muted, undo glyph, not a peer of the primary Export). "GIF Look" is a preset that writes several rows and flips to Custom on manual edit. All four groups (Output / Playback / Quality / Optimization, ~25 rows) follow this.
