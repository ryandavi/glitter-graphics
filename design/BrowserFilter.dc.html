Search/filter is collapsible EVEN WHILE ACTIVE — this was previously a hard rule ("stays expanded while a search or filter is active"); Ryan-said that traps the user with a row they can't dismiss. Two states shown side by side: expanded-and-closable (left, new .closebtn) and collapsed-with-dot (right, new .icnbtn .dot). Real touch points: (1) .search-toggle-row gets an explicit close action, not just the existing blur-to-collapse; clicking it forces .search-collapsed regardless of active state. (2) The collapsed icon shows a dot when .has-active-search/.has-active-filters is set on .glitter-search, independent of the row's own expand/collapse state — the CSS classes that already exist (css/panels/_gallery.scss:97-98) just also drive this badge now. (3) The active-filter summary row (.active-filter-summary) is UNCHANGED by any of this — it's a separate "what's applied" readout, not the search controls, and stays visible regardless of whether the controls are collapsed.
