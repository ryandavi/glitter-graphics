Gradient is a third Source mode of the shared paint-slot module (beside Glitter / Solid), reconciled with the live app (js/effects/effect-source.js, CONFIG.rendering.gradient). Stop handles are circles sitting on the bar (matching the app's .gradient-preview-stop). The stop LIST shows every stop; Pos / Alpha use the standard .num readout with a % suffix (alpha has no slider — a deliberate space tradeoff; the compact field is the cost of keeping every stop visible). Add stop and Reverse are a 2-up of the standard .btn (the Open/Save pair pattern), not accent text or icon buttons. Type = segmented Linear / Radial. Blend = segmented Linear / Smooth / Constant (gradient.interpolation). Angle is a slider, Linear only (when:). The divider above Type is full-bleed. One Opacity row (the fill's), inside the module.
Midpoint diamonds between stops (drag to bias the blend toward one side) are drawn here but are not in the app yet — CONFIG.rendering.gradient has no per-segment midpoint. Implementing them means adding a midpoint (0–1) to each stop pair and honouring it in getEffectGradientRenderStops() / createEffectCanvasGradient(). Ship the rest without the diamonds if that's out of scope for now.
