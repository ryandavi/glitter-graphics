Deltas: current app vs this design

Every line below is the codebase as it stands today compared to what this design specifies. It is written to hand to an implementer.

Add = this design shows it as a real control; the app has no equivalent yet.

Remove / replace = exists in the app now; this design eliminates or supersedes it.

Keep = exists in the app now; this design preserves it, possibly restyled.

Parked = discussed, not in this design. Revisit separately.

Nothing here may break the preservation contract: tests/panel-parity.js requires the set of element ids in each section to stay identical.

This sheet plus the Panels Inventory are the running record; they stay current as the panels iterate.

System rule, not a feature: concentric radii

Rounded elements nested in rounded elements step the radius down by the gap between them (window 8, card 6, field 4, inner 3), recursively, floored at 3. Tokens --r-panel / --r-card / --r-field / --r-inner. Apply across the whole app.

Add — not in the app today

Appears in the mockup as a real control. Confirmed in scope.

Editable Scale field

Today Scale is scaleReadout: true, display only. Make it a field that types a percent and drives W / H proportionally.

Shape corner radius

LayerType.SHAPE has no radius control. Add a bounded slider on the shape asset (rounded-rectangle and similar).

Type-to-set number fields

Most numeric values are slider-only today. Every value in the mockup is an editable field; X / Y / W / H / Scale have no slider at all.

Container-query responsive layout

.settings-group-two-column is 2-up at every width, no query anywhere. Needs container-type: inline-size plus stack rules under ~360px.

Opt-in collapsibility

initializeAdvancedDisclosures() stamps every .subsection-content-group as collapsible. Make it opt-in per schema item, so only modules and the Advanced disclosure collapse.

Panel scroll region + sticky footer

Auto Glitter needs a scrolling body with a pinned "Create Layers" action, a live status host and a dynamic results list. Needs .panel-scroll + .panel-footer primitives that do not break the spacing rules.

Parked — discussed, not in this design

Too involved or undecided. Kept here so they are not lost, not built now.

Saved styles / presets

Save a Fill + Border + Shadow combination as a named style and re-apply it. New storage + picker. Complex. Not now.

Stacked effects

Allow more than one Border / Shadow (a second shadow, an inner glow). Not now.

Copy source between paint slots

"Use same glitter as Fill" for Border / Shadow. Not now.

Blend mode on fills

Normal / Multiply / Screen / Overlay over the base. Undecided.

Eyedropper for Solid

Pick a color off the canvas for a solid source. Undecided.

Remove / replace — in the app now

Migrated deliberately, one work package at a time. No selector disappears in the same commit that introduces its replacement.

Eight label vocabularies

setting-label, effect-option-label, functional-control-group-title, advanced-control-group-title, control-group-label, settings-row-label-main all collapse to .property-label and .property-group-label.

Auto-collapsible cards

Every L2 card is currently made collapsible with an injected chevron. Becomes opt-in.

Per-slider "Reset" link row

Every slider gets a full-width <button>Reset</button> on its own third row (34 of them in the text panel). Replaced by the one revert icon in the row.

Free-form module summaries

"Solid, 2, 3, 35%" value dumps in collapsed headers. Replaced by one identifier.

Wrapping segmented control

Two segmented visuals exist (one-line and one that wraps). The wrapping one goes; large sets use a dropdown or .choice-grid.

Redundant title / label pairs

A card titled "Opacity" wrapping one row labelled "Opacity" (measured 120px tall for one slider). The block drops its title when it would equal the control's label.

settings-row-* modal vocabulary in the sidebar

Canvas Size is authored in modal markup and moved into the panel at boot. Re-authored in the row vocabulary (Canvas Properties + No-selection Size).

Five inconsistent empty states

Three use an icon-wrapper xl SVG, three use a literal emoji. Become one .property-empty component.

Filter sections are cards

Each .filter-section has a card background, radius, padding (six stacked cards in the drawer). Become label + chips separated by hairline dividers.

filter-label is a fourth uppercase level

Collapses into .property-group-label, the one uppercase level.

Nested scroll trap in the filter drawer

.filters-container-inner has max-height:200px; overflow-y:auto inside the already-scrolling panel. Removed; the panel scrolls.

Keep — in the app now, preserved

Asset dimensions and frame count

Reconsidered: staying. Useful, especially stickers ("512 x 512") and animated glitter ("12 frames"). One muted meta line under the name, not a metadata grid. Frame count + Animated badge only when frames > 1.

L0 accordion, one open at a time

The Y2K gloss bar (windows7-bar mixin) stays. This is where the era chrome lives.

Font picker

renderFontPicker() preview cards, sample rendered in the face. Unchanged.

buildAssetInfo component

Already one shared asset-summary component with a compact variant. Only styling / placement changes.

All element ids and manager bindings

Managers bind by id. Every stamped id keeps its legacy name; only structure and CSS change.

Image Size: Scale Textures / Scale Effects

Both toggles stay, under the Image Size mode of the Canvas Size control. Earlier draft wrongly implied they were dropped.

Canvas Size: anchor grid + extension fill

The 9-cell anchor (canvasSizeAnchor) and the Transparent / Color extension with a conditional fill-color row stay, re-drawn in the row vocabulary.

Palette: Posterize and Dither branches

One module, one Mode switch. The mid rows swap between the two; both branches kept (Cleanup for Posterize; Algorithm / Color palette / Pattern / Shimmer for Dither).
